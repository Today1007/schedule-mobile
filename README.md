# 日程安排 · 手机单机版

这是可发布到静态网站的手机版。打开网址后，手机默认显示日视图；可以添加、编辑、删除笔试、面试和其他事项，并导出 JSON 备份或 ICS 日历文件。

将 `index.html`、`app.js`、`styles.css`、`manifest.webmanifest`、`sw.js` 和两个 PNG 图标放在同一网站目录。网站需使用 HTTPS，才能安装到手机桌面并缓存页面供离线打开。

日程保存在当前手机浏览器的本地存储中，不会与原 `chatgpt.site` 网站或其他设备自动同步。清理浏览器网站数据前应先点击“备份数据”。直接以 `file://` 打开 HTML 时，浏览器对本地存储的支持不统一，因此正式使用应部署到 HTTPS 网站。
